# Getting help

Start with the affected repository's README, troubleshooting guide, and existing
issues, where enabled. Open an issue there for a reproducible bug or a proposed
change. Include the version and a minimal example using synthetic data. If issues
are disabled, follow the repository's support instructions or contact a maintainer.

For changes to shared contribution guidance, templates, or reusable workflows,
open a pull request in the [shared `.github` repository](https://github.com/dkvirtual/.github/pulls).

For vulnerabilities or exposed credentials, follow [SECURITY.md](SECURITY.md).
Never include private logs, access tokens, or customer information in an issue.
