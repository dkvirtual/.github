# Getting help

Start with the affected repository's README, troubleshooting guide, and existing
issues. Open an issue there for a reproducible bug or a proposed change. Include
the version and a minimal example using synthetic data.

Use this repository's issues for shared contribution guidance, templates, or
reusable workflows.

For vulnerabilities or exposed credentials, follow [SECURITY.md](SECURITY.md).
Never include private logs, access tokens, or customer information in an issue.
